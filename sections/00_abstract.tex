\begin{abstract}
% A common machine-learning technique adds an \emph{auxiliary loss}
% that pushes a network's features toward a known target direction
% (e.g., positive vs. negative sentiment, or calming vs. disturbing
% emotion). We test $25$ such recipes (knowledge distillation,
% representational-similarity analysis, contrastive losses, low-rank
% adapters, channel-targeted brain-region losses) on
% FACED~\citep{chen2023faced}, a public EEG-emotion dataset ($123$
% subjects, $28$ video clips, $9$ classes). None help: $16$ produce
% statistically significant accuracy decrements; $0$ produce gains. We
% trace this to a regularity we call \emph{saturation} (in our setting,
% a converged FACED-9 classifier whose penultimate features already
% encode a measurable valence direction): once the network has reached
% this regime from task labels alone, the auxiliary loss adds gradient
% noise rather than information. Saturation is distinct from
% overfitting (memorising the training set); it is a property of how
% task and auxiliary supervision interact once both target the same
% direction in feature space. The same picture suggests a positive
% prescription: ensemble across the seed-specific differences in the
% features, rather than supervise the part of the features that has
% already saturated. Following this prescription on FACED yields a new
% state of the art at $\mathbf{0.6948}$ balanced accuracy---a $+10.5\%$
% relative improvement over EMOD~\citep{chen2025emod}, the previous SOTA
% on FACED, at $0.6287$. Surprisingly, the language-model-derived class
% prototypes used by the knowledge-distillation step in our recipe are
% interchangeable with random orthonormal vectors ($\Delta\le 0.003$
% balanced accuracy): the SOTA gain comes from the \emph{shape} of the
% loss (a 9-class structure imposed on the features), not from the
% \emph{content} of the prototypes. To probe what the network has
% saturated on---and to demonstrate it is a real semantic axis, not a
% noise dimension---we extract one direction explicitly. We write nine
% short emotion-evocative stories (one per FACED class), pass them
% through a language model (Qwen3-4B), and take the first principal
% component of the language model's late-layer features across the nine
% stories. We call this direction the \emph{valence axis}. The same
% direction predicts movie-review sentiment zero-shot on
% SST-2~\citep{socher2013recursive} at AUC $0.832$, predicts the EEG
% response averaged across $123$ FACED subjects at $r=0.80$ ($r=0.87$
% when the V-axis is built from CLIP-text embeddings of the same
% stimulus descriptions), and emerges spontaneously in $36$ EEG
% classifiers trained only on the $9$ emotion
% labels. All claims replicate on a second public EEG dataset,
% SEED-V~\citep{liu2022seedv} (Appendix~\ref{app:seedv-full}).
A standard way to inject prior knowledge into a neural network is an auxiliary loss that pulls its features toward a known concept direction. We report that this strategy fails once the network has already converged on the concept from task labels alone. On FACED, a nine-class EEG emotion benchmark, twenty-five such recipes---knowledge distillation, representational similarity, contrastive, and topographic losses---applied to a converged classifier improve accuracy in none of the cases and significantly reduce it in fifteen. The effect flips sign with baseline strength: the same valence loss is within seed noise of zero on a weak backbone ($+0.006$ balanced accuracy, $p{=}0.41$) but significantly hurts the converged one ($-0.029$, Holm-corrected $p{=}0.011$). The effect is specific to neither the concept nor the modality. An arousal target hurts the converged backbone just as much ($-0.035$, $p{=}0.007$); and on a CIFAR-10 image classifier, an auxiliary head that significantly helps while the backbone is still training stops helping once it converges---with an aligned target statistically indistinguishable from a random one throughout. We name this the \emph{saturation regularity}: once task labels have driven the classifier onto the target concept, added supervision deforms an already-converged representation without improving generalization---training accuracy stays at ceiling while test accuracy falls.
Saturation has a constructive corollary. The class-mean structure of the features is shared across seeds, whereas the within-class residual is seed-specific and load-bearing. Ensembling across this residual diversity, rather than supervising the saturated basin, reaches a new FACED state of the art: $0.6755$ balanced accuracy from a single model ($+7.4\%$ over the previous best single model, EMOD at $0.6287$) and $\mathbf{0.6948}$ from a ten-checkpoint ensemble. On a second EEG dataset, SEED-V, the same auxiliary supervision again yields no gain ($\Delta{=}{+}0.0018$, paired $p{=}0.38$, within seed noise), consistent with saturation.
To identify what the network has saturated on, we extract the concept explicitly as a one-dimensional valence direction (the \emph{V-axis}) from nine short stories passed through a language model. This direction predicts movie-review sentiment zero-shot (AUC $0.832$), tracks the cohort-averaged EEG response to affective videos ($r{=}0.80$; $r{=}0.87$ for a CLIP-text axis built from the same stimulus descriptions), and is encoded---without ever being supervised---by the converged EEG classifiers themselves. The transfer is valence-specific but not V-axis-specific---a generic valence axis performs identically---and population-level rather than within-subject. Saturation is thus a property of the converged representation, not of any particular concept or source model.
\end{abstract}
