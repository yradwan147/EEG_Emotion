\begin{abstract}
% A common machine-learning technique adds an \emph{auxiliary loss}
% that pushes a network's features toward a known target direction
% (e.g., positive vs. negative sentiment, or calming vs. disturbing
% emotion). We test $25$ such recipes (knowledge distillation,
% representational-similarity analysis, contrastive losses, low-rank
% adapters, channel-targeted brain-region losses) on
% FACED~\citep{chen2023faced}, a public EEG-emotion dataset ($123$
% subjects, $28$ video clips, $9$ classes). None help: $16$ produce
% statistically significant accuracy decrements; $0$ produce gains. We
% trace this to a regularity we call \emph{saturation} (in our setting,
% a converged FACED-9 classifier whose penultimate features already
% encode a measurable valence direction): once the network has reached
% this regime from task labels alone, the auxiliary loss adds gradient
% noise rather than information. Saturation is distinct from
% overfitting (memorising the training set); it is a property of how
% task and auxiliary supervision interact once both target the same
% direction in feature space. The same picture suggests a positive
% prescription: ensemble across the seed-specific differences in the
% features, rather than supervise the part of the features that has
% already saturated. Following this prescription on FACED yields a new
% state of the art at $\mathbf{0.6948}$ balanced accuracy---a $+10.5\%$
% relative improvement over EMOD~\citep{chen2025emod}, the previous SOTA
% on FACED, at $0.6287$. Surprisingly, the language-model-derived class
% prototypes used by the knowledge-distillation step in our recipe are
% interchangeable with random orthonormal vectors ($\Delta\le 0.003$
% balanced accuracy): the SOTA gain comes from the \emph{shape} of the
% loss (a 9-class structure imposed on the features), not from the
% \emph{content} of the prototypes. To probe what the network has
% saturated on---and to demonstrate it is a real semantic axis, not a
% noise dimension---we extract one direction explicitly. We write nine
% short emotion-evocative stories (one per FACED class), pass them
% through a language model (Qwen3-4B), and take the first principal
% component of the language model's late-layer features across the nine
% stories. We call this direction the \emph{valence axis}. The same
% direction predicts movie-review sentiment zero-shot on
% SST-2~\citep{socher2013recursive} at AUC $0.832$, predicts the EEG
% response averaged across $123$ FACED subjects at $r=0.80$ ($r=0.87$
% when the V-axis is built from CLIP-text embeddings of the same
% stimulus descriptions), and emerges spontaneously in $36$ EEG
% classifiers trained only on the $9$ emotion
% labels. All claims replicate on a second public EEG dataset,
% SEED-V~\citep{liu2022seedv} (Appendix~\ref{app:seedv-full}).
\xuhui{Large language models (LLMs) have become powerful general-purpose representation learners, with growing evidence that their internal features align with human cognition across high-level concepts. In this paper, we investigate this alignment for emotional valence and make four contributions.
First, we discover and verify a one-dimensional valence direction inside modern LLMs. Using just nine emotion-evocative sentences, we construct the valence direction, named the V-axis, from modern LLMs, and verify it through zero-shot transfer to standard sentiment benchmarks and cross-model consistency across fourteen LLMs of widely varying scale.
Second, we show the V-axis is shared with the human brain signals. On a public EEG cohort of 123 subjects watching affective videos, a single linear projection on EEG features tracks the V-axis position of each stimulus. More strikingly, we train 36 EEG emotion classifiers without ever exposing them to the V-axis, yet their internal features spontaneously rediscover it. Modalities and supervision regimes converge on the same valence direction.
Third, we identify a saturation regularity that explains why the shared direction is not a usable supervision target. We test twenty-five standard alignment recipes spanning knowledge distillation, RSA, contrastive, and topographic losses; none help, and sixteen significantly hurt accuracy. We attribute this to saturation: once task labels alone have driven the network onto the target direction, additional supervision can only deform an already-saturated basin while the load-bearing within-class residual receives no gradient.
Fourth, the same mechanism prescribes a remedy. Ensembling across residual diversity, rather than supervising the basin, improves balanced accuracy by 10.5\% over the prior best on FACED, a public EEG emotion recognition benchmark, with the same effect replicating on the SEED-V dataset.}
\end{abstract}
